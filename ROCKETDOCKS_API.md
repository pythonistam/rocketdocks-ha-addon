# Что аддон HA «RocketDocks» ожидает от программы RocketDocks

ТЗ для проекта RocketDocks. Аддон — это nginx за Ingress Home Assistant: он подставляет ключ и
проксирует запросы на компьютер. Всё ниже нужно со стороны программы.

## 1. Веб-сервер

- HTTP (без TLS), IPv4, слушает `0.0.0.0:<WebPort>`, порт по умолчанию **8790**, меняется в настройках.
- Включается и выключается пользователем (по умолчанию выключен). Состояние и порт хранятся в `RocketDocks.ini`.
- Принимает подключения только из частных подсетей: 10/8, 172.16/12, 192.168/16, 127/8, 169.254/16.
  HA стоит на 192.168.31.111.
- Правило брандмауэра Windows для входящего TCP на порт, только локальная подсеть (кнопка «Разрешить в брандмауэре», один запрос UAC).
- Ответы `Connection: close` допустимы. HTTP/1.1, без gzip (или с gzip, аддону это не мешает).

## 2. Ключ доступа

- Случайный, 128 бит, **32 hex-символа** (`^[0-9a-fA-F]{32}$`). Аддон проверяет именно этот формат.
- Обязателен для каждого запроса. Принимается любой из способов: заголовок `X-Api-Key: <key>`
  (его шлёт аддон), `Authorization: Bearer <key>` или `?key=<key>`.
- В интерфейсе: показать ключ, скопировать, создать новый.
- Неверный ключ отдаёт `401`. Защита от подбора: после 20 ошибок с адреса за 10 минут отвечать `429`
  в течение 10 минут. Аддон делает при старте только одну пробную попытку.

## 3. Эндпоинты

| Метод и путь | Ответ |
|---|---|
| `GET /` | HTML-страница панели (см. п. 4) |
| `GET /api/state` | JSON со списком значков (см. ниже) |
| `GET /api/icon?id=N&v=V` | PNG текущей картинки значка N; `v` — версия, для кэша |
| `POST /api/click?id=N&x=0..1&y=0..1` | `202 {"ok":true}`, `403 {"error":"blocked","reason":"..."}`, `404` |
| `GET /api/events` | поток событий SSE (см. п. 5) |

Формат `/api/state`:

```json
{"app":"RocketDocks","version":"1.0.0.47","cols":12,"rows":2,"side":"bottom","ver":5,
 "items":[{"id":0,"t":"Chrome","x":0,"y":0,"w":1,"h":1,"v":3,"r":1,"b":"danger"}]}
```

Здесь `id` — номер значка, `t` — подпись, `x,y` — клетка, `w,h` — размер в клетках, `v` — версия картинки,
`r` — программа запущена, `b` — щелчок запрещён (`danger`, `uac` или `user`), `ver` — версия списка.

Щелчок выполняется в потоке окна панели, так же как щелчок мышью (ярлык запускается, у доклета
вызывается `OnLeftButtonClick` с точкой `x*ширина, y*высота`). Ответ не ждёт завершения действия.

## 4. Страница панели

- Все ссылки на API **относительные** (`api/state`, `api/icon?...`, `api/events`), без начального `/`.
  Под Ingress страница открывается по адресу `/api/hassio_ingress/<токен>/`, и абсолютные пути сломаются.
- Ключ страница берёт из своего `?key=`. Если его нет, запросы идут без ключа (ключ подставит аддон).
- Параметры: `theme=dark|light|transparent`, `labels=0|1`, `size=<px клетки>`. Аддон передаёт их из своих настроек.
- Нельзя отдавать `X-Frame-Options`. Нужно `Content-Security-Policy: frame-ancestors *`,
  потому что страница открывается внутри HA в iframe.
- Сетка повторяет раскладку панели (cols × rows, клетки и размеры значков). Щелчок по значку отправляет
  `POST api/click` с долей точки внутри значка. Запрещённые значки показаны приглушёнными.
- Страница переподключается к событиям при обрыве, а после переподключения перечитывает `api/state`.

## 5. События (SSE)

- `GET /api/events`, `Content-Type: text/event-stream`, заголовок `X-Accel-Buffering: no`.
- `event: hello` с текущей версией списка при подключении.
- `event: list` с новой `ver`, когда изменились значки, подписи, раскладка или «запущено».
- `event: icons` с данными `{"<id>": <ver>, ...}`, когда доклет сменил картинку (`SetImage`).
- Пинг-комментарий `: ping` каждые 15 с (аддон держит поток до 1 часа без данных).
- Не больше 8 одновременных потоков.
- Пока открыт хоть один поток, доклеты не «усыпляются», даже если панель на ПК скрыта.

## 6. Безопасность удалённых щелчков

- Удалённо разрешён только левый щелчок.
- Запрещены значки: `[Quit]`, `[Settings]`, питание, службы, очистка, автозагрузка, процессы, Корзина,
  cmd/PowerShell, программы с UAC. Пользователь может запретить и любой другой значок.
- Во время удалённого щелчка меню, диалоги и запросы UAC доклетов не открываются: на ПК никто не
  может на них ответить.

## 7. Проверка

```powershell
curl.exe -H "X-Api-Key: <ключ>" http://<IP ПК>:8790/api/state
```

Ответ `200` с JSON означает, что аддон подключится.
