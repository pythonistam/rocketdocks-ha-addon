# RocketDocks

Показывает панель RocketDocks с компьютера прямо в Home Assistant: те же значки и доклеты,
та же раскладка, щелчок по значку в HA работает как щелчок мышью на компьютере.
Изменения (живые доклеты, запущенные программы) приходят сразу.

## Подготовка на компьютере

1. В RocketDocks: правый щелчок по панели -> **Настройка панели…** -> вкладка **Веб-панель** ->
   флажок **Включить веб-панель (локальная сеть)**.
2. Там же нажать **Разрешить в брандмауэре** (один запрос UAC) и скопировать **Ключ доступа**.
3. IP компьютера виден в поле **Адрес (с ключом)**. Компьютер и Home Assistant должны быть в одной
   подсети: правило брандмауэра пропускает только локальную подсеть.
4. Значки, которые нельзя нажимать из HA, перечисляются в поле **Не нажимать удалённо**.

## Настройка аддона

| Параметр | Что указать |
|---|---|
| `host` | IP компьютера, например `192.168.31.50` (лучше закрепить его за ПК в роутере) |
| `port` | порт веб-панели, по умолчанию `8790` |
| `key` | ключ доступа из RocketDocks |
| `theme` | `dark`, `light` или `transparent` |
| `labels` | подписи под значками |
| `size` | размер клетки в пикселях, `0` — как на компьютере |

После запуска в боковом меню появится пункт **RocketDocks** (включите «Показать на боковой панели»
на странице аддона). Чтобы панель была ещё и вкладкой дашборда, добавьте вид с карточкой
«Веб-страница» (`iframe`) и адресом пункта меню, например `/hassio/ingress/<слаг_аддона>`.

## Безопасность

- Ключ хранится только в настройках аддона и добавляется прокси к каждому запросу; в браузер он не попадает.
- Прокси принимает подключения только от Ingress (то есть только после входа в Home Assistant).
- RocketDocks отвечает только адресам локальной сети и не даёт удалённо нажимать опасные значки
  (выход, настройки, питание, службы, очистку, программы с UAC).
- Неверный ключ RocketDocks считает подбором: после 20 ошибок адрес HA блокируется на 10 минут.
  Аддон проверяет формат ключа и делает при старте только одну пробную попытку.

## Если не работает

Смотрите журнал аддона: там видно, отвечает ли компьютер и принят ли ключ.
